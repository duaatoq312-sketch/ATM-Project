\# ATM System (C++)



A console-based ATM application developed in C++ that simulates common banking operations through a simple client account workflow. The system uses file-based storage to load account information, process transactions, and save updated balances.



\## How It Works



The application starts with client authentication. After successfully logging in, the client can access a range of ATM operations such as withdrawing money, depositing funds, and checking the current account balance.



Transactions update the stored account data so that changes remain available when the application is run again.



\## Main Features



\* Client authentication through username and password

\* Quick withdrawal with predefined amounts

\* Custom withdrawal for user-specified amounts

\* Deposit operations

\* Balance inquiry

\* Automatic balance updates after transactions

\* File-based storage for client information

\* Simple menu-driven ATM interface
